
# YuvaIntern - Task 1: Fundamentals and Setup

## Project Overview
This project is a simple Hello World web application created
as part of the Full Stack Developer Fresher internship.

## Objective
To set up the development environment, understand project
structure, and create a basic working web application.

## Technologies Used
- HTML5 for webpage structure
- CSS3 for styling and layout
- JavaScript for button interaction
- Visual Studio Code as the code editor
- Git and GitHub for version control

## Project Structure
- index.html: Main webpage
- css/style.css: Styling
- script.js: Button interaction
- README.md: Project documentation

## Features
- Displays a Hello World heading
- Uses a centered card layout
- Includes a clickable button
- Shows a success message after clicking the button

## How to Run
Open index.html in a web browser and click the Click Me button.

## Learning Outcomes
Learned basic HTML, CSS, JavaScript, project organization,
and development environment setup.

## Conclusion
The project demonstrates a basic working web application
and provides a foundation for learning full-stack development.
